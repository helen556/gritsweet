# Асети та їх ролі

Оригінали лежать у `assets-src/` (не змінюються). Оптимізовані версії генеруються командою
`npm run assets:build` у `public/media/` (AVIF + WebP, кілька ширин, `srcset/sizes`, `width/height`).
Розміри та доступні ширини записуються в `src/lib/media-manifest.json`.

**Не використовується на сайті:** `characters-reference.png` — робочий референс персонажів (не фон і не товар),
тому не завантажується покупцеві й не додано в репозиторій. `client-brief.pdf` — бриф, **не книжка**, у продаж не потрапляє
й у репозиторій не додано (публічний репозиторій). Російськомовні тексти з брифу на сайт не перенесено.

## Hero-відео
- `muted` + `playsInline`, autoplay, якщо браузер дозволяє; програється **один раз** і лишається на останньому кадрі (без петлі).
- Кнопки «Пауза» / «Переглянути ще раз» / «Відтворити».
- `prefers-reduced-motion` або Save-Data → постер `hero-start` без autoplay, з кнопкою відтворення.
- Помилка відео або заблокований autoplay → `hero-start` + кнопка відтворення.
- Мобільне кадрування: герої рухаються справа до центру, Лілі тягне руку ліворуч — вузький portrait-crop сховав би дію.
  Тому відео завжди 16:9 без обрізання: на мобільному — окремий блок на всю ширину, текст нижче; на desktop — праворуч від тексту.
- Прямий погляд героїні **не реалізовано** (потрібна нова генерація відео); CSS-фільтри для «корекції очей» не застосовуються.
