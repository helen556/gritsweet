## Hero-відео
- `muted` + `playsInline`, autoplay, якщо браузер дозволяє; програється **один раз** і лишається на останньому кадрі (без петлі).
- Кнопки «Пауза» / «Переглянути ще раз» / «Відтворити».
- `prefers-reduced-motion` або Save-Data → постер `hero-start` без autoplay, з кнопкою відтворення.
- Помилка відео або заблокований autoplay → `hero-start` + кнопка відтворення.
- **Повноекранний hero (100svh, fallback 100vh) на desktop і mobile**; header лежить поверх. Відео ніде не обрізається, щоб не сховати обличчя Лілі, руку в момент запрошення (≈3–4 с) і родину у фіналі (≈5.5–8 с) та знак Kling:
  - екрани від 4:5 до 16:9 (ноутбуки, 1440×900): відео на всю ширину, прив’язане до низу; вузька смуга під header — розмитий постер;
  - ширші за 16:9 (широкі монітори, телефон landscape): відео на всю висоту праворуч, назва — зліва над розмитим фоном;
  - вертикальні (телефони 360×800, 390×844): розмитий статичний постер на весь екран, попереду чітке відео `contain` з м’якими краями, назва на хмаринці зверху, CTA «До книжок» знизу — резервна композиція до появи вертикального ролика.
  Позиції перевірено на кадрах 0.4 с, 3.6 с і 7.9 с для 1440×900, 1920×950, 844×390, 390×844, 360×800.
- **Назва на хмаринці**: справжній `h1`; хмаринка — CSS-шари (без растрових файлів); порядок: пил (0–1.1 с) → хмаринка → назва → слоган і CTA (до ~2 с), один раз за сесію.
- **Заміна ролика одним місцем**: масив `SOURCES` у `src/components/Hero.tsx` (+ постер у `scripts/build-assets.ts`), після чого — перевірка кадрування за чек-листом вище.
- Прямий погляд героїні **не реалізовано** (потрібна нова генерація відео); CSS-фільтри для «корекції очей» не застосовуються.

## Нові матеріали (оновлення 13.10.2026): як додати

Покладіть файли в `assets-src/` з такими назвами і виконайте `npm run assets:build && npm run db:setup`
(або завантажте те саме через адмінку — результат однаковий). Поки файлу немає, відповідний блок
**не показується** (разом із заголовком, фоном і відступами), а книжка без обкладинки не з'являється на вітрині.

| Файл | Що вмикає |
|---|---|
| `hero-desktop.mp4` | Відео першого екрана для комп'ютера. Копіюється **без перекодування** (оригінальна якість), постер — перший кадр |
| `hero-mobile.mp4` / `.mov` | Окреме відео для телефона й вертикального планшета (`max-aspect-ratio: 4/5`). Завантажується лише одне з двох |
| `covers/<slug>-uk.jpg`, `covers/<slug>-en.jpg` | Обкладинка UA / EN-видання. Slug: `lili-ide-do-likarya`, `yak-lili-navchylasia-sidaty-na-horshchyk`, `yak-lili-vchyla-bublyka`, `lili-vchytsya-druzhyty`, `lili-ta-kazka-pro-son`, `komplekt-5-knyzhok`. **Заміна наявної обкладинки** — файл із версією `<slug>-uk@v2.png` (нова адреса файлів, тож браузери й CDN не показують стару з кешу); `db:setup` сам підставить нову обкладинку замість попередньої з пакета (завантажені в адмінці не чіпає) |
| `books-table.jpg` | Атмосферний блок «Про книжки» (фото праворуч, розчиняється в молочне тло) |
| `spreads/<slug>-01.jpg`, `-02.jpg`… | Блок «Книжка зсередини» зі збільшенням. Лише справжні розвороти |

Кадрування hero (точка фокусу, бік тексту, тривалість м'якого стику повтору) — у `src/content/hero.ts`.
Поки нових відео немає, працює запасний режим зі старим `hero-final.mp4` (без обрізання персонажів).

### Телефонне відео (додано 13.10.2026)
`hero-mobile.mov` — HEVC (H.265), 1214×2160, 24 к/с, 7.04 с, без звуку.
- `public/media/hero-mobile.mp4` — **оригінальний потік без перекодування** (лише перепакування в MP4 з `faststart`). Його відтворюють Safari/iOS, більшість сучасних Android і Chrome/Edge з апаратною підтримкою HEVC.
- `hero-mobile-h264.mp4` (H.264, CRF 17, та сама роздільність) і `hero-mobile.webm` (VP9) — лише для браузерів без HEVC. Кожен браузер завантажує тільки одне джерело.
- Заставка — кадр 3.0 с (Лілі дивиться в камеру; задається в `assets-src/hero.json`), бо перший кадр — порожній сад. Перший кадр збережено окремо: у нього м'яко (700 мс) розчиняється кінець ролика перед повтором, тож різкого стрибка від родини на стежці до порожнього саду немає.
- Кадрування: `object-position: 50% 30%`, назва, вступ і кнопка — внизу, на стежці; обличчя Лілі й голови родини не перекриваються (перевірено на 360×780, 390×844, 768×1024).
- Оригінал `.mov` не зберігається в git (`.gitignore`), згенеровані файли — у `public/media`.

### Відео для комп'ютера (додано 13.10.2026)
Надане «Browser hero»: H.264, 910×512, 30 к/с, 7.04 с. **На прохання власниці обрізано знак «KlingAI 3.0»**: прибрано нижні 36 px
(там лише розмите листя переднього плану; голови, обличчя й собака не зачеплені) → 910×476. Обрізання потребує одного перекодування —
зроблено з дуже високою якістю (x264 CRF 14, без фільтрів, без зміни розміру й частоти кадрів). Далі збірка лише перепаковує файл.
- `public/media/hero-desktop.mp4` (H.264) + `hero-desktop.webm` (VP9, для браузерів без H.264).
- Заставка — перший кадр (Лілі з Бубликом на сходинці). Кадрування `50% 20%` (зберігає верх кадру з головами), текст ліворуч.
- Перевірено: 1440×900, 1920×950, 1280×720, 844×390 (телефон горизонтально) — обличчя не перекриті, знака немає.
- Старий `hero-final.mp4` більше не показується (лишається в коді як запасний варіант, якщо файл видалити).
