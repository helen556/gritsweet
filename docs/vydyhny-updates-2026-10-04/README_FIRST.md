# Як передати пакет Claude Code

1. Розпакуй ZIP у папку поточного проєкту «Видихни», наприклад у docs/vydyhny-updates-2026-10-04.
2. Старий пакет та вихідний код залишаються потрібними. Тут лише нові 4 референси і повний опис нинішніх змін.
3. Надішли Claude Code таке завдання (підстав фактичний шлях):

«Прочитай docs/vydyhny-updates-2026-10-04/CLAUDE_PROMPT.md, переглянь усі 4 PNG у references і реалізуй усі описані зміни в цьому репозиторії. Цей промпт має пріоритет над попередніми описами глини, валют і першого екрана. Відтвори погоджені матеріали й перевір жести, звуки та мобільний вигляд. Виконай реалізацію та QA, а не лише план».

Якщо працюєш у чаті з підтримкою ZIP, прикріпи архів і попроси розпакувати та прочитати CLAUDE_PROMPT.md. Якщо ZIP не читається — розпакуй і прикріпи Markdown та чотири PNG окремо. Не припускай, що архів автоматично відкривається в кожному режимі Claude.

## Що всередині
- CLAUDE_PROMPT.md — правки, нові сцени, тексти, жести, звук, інтеграції та перевірки.
- references/01_dishes_and_bottle.png — посуд і пляшка.
- references/02_candle.png — свічка.
- references/03_bubble_wrap.png — пакувальна плівка замість глини.
- references/04_beverage_can.png — відкривання банки.
- manifest.json — розміри й контрольні суми оригінальних зображень.

PNG — референси вигляду, а не готові інтерактивні сцени. Звуків, 3D-моделей, старих референсів, hero-відео й вихідного коду в цьому ZIP немає; джерела для старих сцен використовуються з наявного проєкту. Ніяких ключів чи токенів у пакеті немає.
