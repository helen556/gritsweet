# Видихни — пакет для Claude Code

Розпакуй цей пакет у корінь ІСНУЮЧОГО вихідного репозиторію як папку Vydyhny_Claude_Package. Не розпаковуй у public: промпти й примітки не мають публікуватися як контент сайту. Матеріали для сайту Claude перенесе в належні каталоги.

Дай Claude Code команду:

> Прочитай Vydyhny_Claude_Package/README.md, повністю Vydyhny_Claude_Package/CLAUDE_CODE_PROMPT.md та Vydyhny_Claude_Package/ASSET_MANIFEST.json. Переглянь усі 10 зображень у assets/. Реалізуй описані правки в поточному проєкті, використовуючи ці матеріали. Почни з аудиту й відповідності файлів сценам, далі виконуй завдання та перевірки. Фото — референси, а не заміна інтерактивних механік.

Основне завдання — CLAUDE_CODE_PROMPT.md. SCENE_CONCEPTS.md містить історію погоджених концепцій; за розбіжностей остаточний промпт має пріоритет. ASSET_MANIFEST.json задає точні шляхи, ролі й контрольні суми. Чат створюється кодом. Початкові та фінальні фото мають бути перетворені на інтерактивні сцени з потрібними окремими шарами.

Комплект: 2 банкноти, 2 стани рюкзака, 2 стани пряжі, 1 погоджений лоток, 1 фото глини, 2 стани карти. Відхилені варіанти лотка, дублікати карт і скриншот DeepState не включено. Hero-відео зберегти з поточного репозиторію. Цей пакет не містить вихідного коду сайту чи секретів.
