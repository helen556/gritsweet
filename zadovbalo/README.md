# Видихни

Український інтерактивний простір: людина пише, що накипіло, і власними рухами взаємодіє з матеріальною метафорою проблеми.
Не психотерапія, не діагнози, не реєстрація. Окремий Next.js 16 застосунок у підтеці репозиторію (сайт у корені не зачіпає).

## Запуск

```bash
cd zadovbalo
npm install
cp .env.example .env.local      # заповнити локально, див. нижче
npm run dev                     # http://localhost:3000
npm run build && npm start      # продакшен
npm run typecheck && npm run lint && npm test
npm run media:hero -- <відео>   # перегенерувати hero-відео (ffmpeg)
npm run map:bake                # перегенерувати контур карти (Крим вилучено)
```

Деплой на Vercel: окремий проєкт, **Root Directory = `zadovbalo`**. Після зміни env — **redeploy**.

## Підключення Cloudflare Workers AI

1. Старий токен, що потрапив у чат, — **відкликати** (Cloudflare → My Profile → API Tokens).
2. Cloudflare → Workers AI → REST API → «Create a Workers AI API Token» (права Workers AI Read + Edit).
3. Вписати в `.env.local` і в Environment Variables хостингу (Production + Preview):
   `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, за бажання `CLOUDFLARE_AI_MODEL`.
4. Для продакшену обовʼязково спільне сховище лімітів: Upstash Redis або Vercel KV
   (`UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN` або `KV_REST_API_URL`/`KV_REST_API_TOKEN`). Без нього AI вимкнений, працює ручний вибір.
5. Redeploy. Перевірка: написати вигаданий текст «кредит 20 тис грн і все на мені» → має зʼявитися «Схоже, зараз найбільше тиснуть…».

Модель за замовчуванням — `@cf/meta/llama-3.3-70b-instruct-fp8-fast` (документована для JSON Mode). Безкоштовний тариф: 10 000 нейронів на добу;
оцінка ~40–50 нейронів на запит (≈ 200 запитів). Тому `AI_DAILY_REQUEST_LIMIT=150` за замовчуванням. На Free перевищення просто дає помилку
(без оплати) — сайт переходить на ручний вибір. Платний тариф і billing не вмикати.

## Архітектура

```
src/
  app/                 сторінки, metadata/OG/sitemap/robots, error/404
    api/analyze        safety → ліміти/бюджет → Cloudflare (таймаут, 1 повтор на 5xx) → zod → постобробка
    api/events         загальні події без змісту
    api/transcribe     серверне STT за інтерфейсом (не налаштовано → 501)
    dev/scene/[id]     службовий перегляд сцени (404 у продакшені без ENABLE_DEV_SCENES)
  components/
    hero/              відео-фон (пауза у фоні/в сцені, reduced motion, Save-Data), перший екран
    flow/              стан-машина, вибір теми/дії, налаштування суми й назв, завершення
    input/             текст, голос
    scenes/            SceneShell (звук, інтенсивність, заново, інша дія, завершити) + 9 сцен окремими чанками
    safety/            екран підтримки
  lib/
    ai/                схема, промпт, провайдер Cloudflare, ключові слова (лише підказка), сума/валюта, клієнт зі скасуванням
    scenes/            реєстр сцен, математика боргу, контур карти
    scene/             canvas, цикл анімації, Pointer Events, поле висот, геометрія, розрив, звук
    server/            ліміти (Upstash/KV або памʼять), логи, request id
```

## Сцени

| Сцена | Тема | Механіка |
| --- | --- | --- |
| Борг | financial_debt | купюри/пачки з вигином і інерцією переносяться на суму; точний нуль |
| Рюкзак | overload | блискавка, предмети різної ваги, три зони |
| Клубок | rumination | Verlet-нитка з натягом, легкий режим, охайний моток |
| Глина | anger | поле висот: вмʼятини в точці дотику, розтяг, стиск, згладжування |
| Папір | anger | розрив за пальцем з волокнами, зминання, шматки з інерцією |
| Лід | anger | тріщини ростуть від дотику, уламки (Вороний) розходяться й тануть |
| Наліпки | hurtful_words | відклеювання з опором і клапаном, чисте скло, зімʼяти |
| Пісок і вода | control / тиха дія | борозни, осипання, камінці, струмок за рельєфом, кола |
| Карта | war_anger (лише після явного вибору) | рвати, палити від точки дотику, умовна ударна хвиля |

## Приватність і безпека

- Текст, сума, власні фрази й відповідь моделі не зберігаються ні в базі, ні в логах, ні в аналітиці, ні в сховищі браузера.
- Перед аналізом — повідомлення про передачу в Cloudflare і ручний вибір без передачі.
- Детермінований safety-шар працює до AI; модельний `needs_support` теж веде на спокійний екран із перевіреними контактами України.
- Логи: лише request id, маршрут, статус, код результату, тривалість.
