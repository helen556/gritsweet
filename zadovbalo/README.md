# Видихни

Український інтерактивний простір: людина пише, що накипіло, і власними рухами взаємодіє з матеріальною метафорою проблеми.
Не психотерапія, не діагнози, не реєстрація. Окремий Next.js 16 застосунок у підтеці репозиторію (сайт у корені не зачіпає).

## Запуск

```bash
cd zadovbalo
npm install
cp .env.example .env.local      # заповнити локально, див. нижче
npm run dev                     # http://localhost:3000
npm run build && npm start      # продакшен
npm run typecheck && npm run lint && npm test
npm run media:hero -- <відео>   # перегенерувати hero-відео (ffmpeg)
npm run map:bake                # перегенерувати контур карти (Крим вилучено)
```

Деплой на Vercel: окремий проєкт, **Root Directory = `zadovbalo`**. Після зміни env — **redeploy**.

## Підключення Cloudflare Workers AI

1. Старий токен, що потрапив у чат, — **відкликати** (Cloudflare → My Profile → API Tokens).
2. Cloudflare → Workers AI → REST API → «Create a Workers AI API Token» (права Workers AI Read + Edit).
3. Вписати в `.env.local` і в Environment Variables хостингу (Production + Preview):
   `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, за бажання `CLOUDFLARE_AI_MODEL`.
4. Для продакшену обовʼязково спільне сховище лімітів: Upstash Redis або Vercel KV
   (`UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN` або `KV_REST_API_URL`/`KV_REST_API_TOKEN`). Без нього AI вимкнений, працює ручний вибір.
5. Redeploy. Перевірка: написати вигаданий текст «кредит 20 тис грн і все на мені» → має зʼявитися «Схоже, зараз найбільше тиснуть…».

Модель за замовчуванням — `@cf/meta/llama-3.3-70b-instruct-fp8-fast` (документована для JSON Mode). Безкоштовний тариф: 10 000 нейронів на добу;
оцінка ~40–50 нейронів на запит (≈ 200 запитів). Тому `AI_DAILY_REQUEST_LIMIT=150` за замовчуванням. На Free перевищення просто дає помилку
(без оплати) — сайт переходить на ручний вибір. Платний тариф і billing не вмикати.

## Як підбирається сцена

Перший екран: «Видихай.» → поле «Що накипіло?» → **одразу сцена** (якщо сенс однозначний) або один короткий вибір «З чого почнемо?» (кілька тем) / одне уточнення / короткий вибір для «Хочу паузу». «Обрати іншу сцену» доступне завжди.

| Приклад | Шлях |
| --- | --- |
| Борги, гроші, сума | Гроші — сума вправи лише в гривнях; долари/злоті з тексту не конвертуються: просимо суму в гривнях |
| Усе на мені | Рюкзак (крок підписів каменів) |
| Думки по колу | Пряжа |
| Хочу навести лад | Пісок і камінці |
| Просто бісить, хочу щось розбити | Посуд (тарілка / пляшка); плівка — альтернатива |
| Хочу полопати плівку | Плівка напряму |
| Хочу тиші | Свічка |
| Сумно, самотньо | «Побудь тут» |
| Втомилась, хочу паузу | Короткий вибір: банка / плівка / свічка |
| Не сказала, не відправила | Символічний чат |
| Злість саме через війну | Карта; страх і горе — тихіша дія (свічка, невисловлене) |

- **Cloudflare Workers AI** (сервер, `/api/analyze`, кнопка «Підібрати сцену»): лише класифікація початкового тексту за схемою JSON; відповідь перевіряється zod, сцени фільтруються за темами, старі назви мігрують (`hurtful_words → unsaid_words`, `stickers → unsaid`, `clay/paper/ice → bubble`).
- **Без ШІ — правила за словами в тексті** (`src/lib/ai/route.ts`, на пристрої, кнопка «Без ШІ» або коли ШІ недоступний): українська/російська/суржик, заперечення, лайка не є темою; конкретна тема важливіша за «бісить»; прямо названа дія («полопати плівку», «запалити свічку») має перевагу. Підписується як «за словами в тексті, без ШІ».
- Статичне превʼю (`NEXT_PUBLIC_STATIC_PREVIEW=1`) чесно показує «Підбір через ШІ зараз вимкнений».

## Архітектура

```
src/
  app/                 сторінки, metadata/OG/sitemap/robots, error/404
    api/analyze        safety → ліміти/бюджет → Cloudflare (таймаут, 1 повтор на 5xx) → zod → постобробка
    api/events         загальні події без змісту
    api/transcribe     серверне STT за інтерфейсом (не налаштовано → 501)
    dev/scene/[id]     службовий перегляд сцени (404 у продакшені без ENABLE_DEV_SCENES)
  components/
    hero/              відео-фон (пауза у фоні/в сцені, reduced motion, Save-Data), перший екран
    flow/              стан-машина з єдиним правилом маршрутизації, вибір, налаштування суми й підписів, завершення
    input/             текст, голос
    scenes/            SceneShell (вступ, підказка, «Звук: увімк./вимк.», «Нова плівка»/«Почати знову», інша сцена, завершити) + 11 сцен окремими чанками
    safety/            екран підтримки
  lib/
    ai/                схема, промпт, провайдер Cloudflare, локальні правила (route.ts), сума/валюта, клієнт зі скасуванням
    scenes/            реєстр сцен (із міграцією старих id), план купюр/пачок, контур карти
    scene/             canvas, WebGL-рендер поля висот (heightgl), цикл анімації, Pointer Events, спрайти, вигин аркуша, розрив, звук
    server/            ліміти (Upstash/KV або памʼять), логи, request id
scripts/assets/        конвеєр матеріалів із фото (Python + OpenCV) → public/scenes/
scripts/audio/         власні звукові семпли (синтез у Python) → public/sounds/
```

## Звуки

Усі звуки — **власні**, синтезовані скриптом `scripts/audio/make_sounds.py` (модальні резонанси кераміки/скла/металу, відфільтрований шум,
вторинні удари), сторонніх записів немає, ліцензія — як у проєкту. Пере-генерувати: `python3 scripts/audio/make_sounds.py`.
Звук вмикається лише перемикачем «Звук» (жест розблоковує AudioContext; вибір памʼятається в localStorage), обмеження 14 голосів + лімітер,
пауза у фоновій вкладці, петлі (дощ, блискавка) зупиняються при виході/вимкненні. Відмова аудіо не ламає жести.

## Приватність і безпека

- Текст, сума, підписи каменів, повідомлення чату й відповідь моделі не зберігаються ні в базі, ні в логах, ні в аналітиці, ні в сховищі браузера.
- Чат «Те, що не встигла сказати» не робить жодних мережевих запитів (перевірено в браузері).
- Біля кнопки «Підібрати сцену» — «Для підбору сцени текст буде передано сервісу ШІ» і розгортання «Як використовується твій текст»; «Без ШІ» — правила на пристрої; «Обрати самому».
- Напис на тарілці, відповідь «Чого бракує?» і текст для близької людини не виходять зі сторінки.
- Детермінований safety-шар працює до AI; модельний `needs_support` теж веде на спокійний екран із перевіреними контактами України.
- Логи: лише request id, маршрут, статус, код результату, тривалість.
