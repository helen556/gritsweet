# Конвеєр матеріалів сцен

Джерело — пакет `Vydyhny_Claude_Package/assets/` у корені репозиторію (фото-референси). Результат — `public/scenes/<сцена>/`.

```
pip install opencv-python-headless numpy scipy
cd zadovbalo/scripts/assets
python3 backpack.py && python3 sand.py && python3 yarn.py && python3 money.py && python3 map.py
python3 bubble.py && python3 dishes.py && python3 candle.py && python3 can.py   # пакет 04.10
```

- `backpack.py` — порожній рюкзак як основа, передній клапан, 6 окремих каменів (приховані частини дорисовано фактурою того ж каменю).
- `sand.py` — лоток без камінців (пісок дорисовано), 13 камінців, карта висот брижів (`height.png`) і маска піску.
- `yarn.py` — заплутана маса без хвоста, клубок, смуга фактури нитки для динамічної нитки.
- `money.py` — лицьовий бік 1000 грн у повній роздільності (лише гривня).
- `bubble.py` — ціла плівка (основа), 82 комірки за зіставленням із шаблоном, атлас лопнутих латок.
- `dishes.py` — стіна без предметів (світло — нормалізована згортка, фактура — латки стіни), тарілка й пляшка (скло напівпрозоре).
- `candle.py` — кадр без полумʼя (горить / не горить), свічка спрайтом, дерево сірника.
- `can.py` — банка без кільця (кришку відновлено), кільце, контур клапана.
- `backpack.py` також вирізає бігунок і язичок блискавки, траєкторію блискавки й безшовну тканину для застебнутої стінки.
- `map.py` — фактура з фото на перевіреному контурі (Natural Earth, без Криму), спрайти полумʼя.
